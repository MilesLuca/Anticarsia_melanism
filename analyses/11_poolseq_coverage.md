# Pool-seq coverage at cortex and in exon/non-exon windows

**Paper:** Figure S6  

Quantify mapping depth at cortex and compare Light-pool depth between exonic and non-exonic windows inside and outside the GWA interval.

## Inputs

- RefSeq annotation `Agem_genome/NCBI/genomic.gff` and its reference FASTA index `GCF_050436995.1_ilAntGemm2_primary_genomic.fna.fai` for section 0.
- The BED/GFF inputs listed below are generated by section 0; normalized bedGraphs are generated by section 2a.
- PoolSeq/q30/plain.q30.sorted.bam and dark.q30.sorted.bam, with indexes.
- PoolSeq/Depth_calculations/depth_cortex_30bp/cortex_padded_30bp.bed and NC_134752.1_full.bed
- PoolSeq/Depth_calculations/depth_cortex_30bp/plain.cortex30.norm.bedgraph and dark.cortex30.norm.bedgraph
- PoolSeq/Depth_calculations/depth_cortex_30bp/cortex_XM_076117071.1.features.uniq.gff
- PoolSeq/Depth_calculations/windows.NC_134752.1.100bp.{EXONONLY,NONEXONONLY}.{IN,OUT}.core200000.bed

## Outputs

- Chromosome, exon-union, non-exonic, GWA and classified-window BEDs; cortex-window BED and transcript GFF.
- `plain.cortex30.norm.bedgraph` and `dark.cortex30.norm.bedgraph`.
- cortex_depth_normalized_with_gene_track_STAKED.pdf
- plain.coverage_hist.100bp_purewindows.core200kb.LINEAR_full.IN_vs_OUT.pdf

## Software

Python 3 (standard library), mosdepth, SAMtools, Bash; R with ggplot2, dplyr, readr, cowplot and data.table.

## Execution and interpretation

1. Figure S6 intentionally uses mean depth: 30-bp cortex windows for S6A and 100-bp exon/non-exon windows for S6B. Figure 2A's median method remains in [analysis 19](19_poolseq_median_depth.md).
2. Run the new preparation script in section 0 with the GFF and FASTA index to create a new `prepared_s6` directory. It supplies all the required BEDs and the cortex transcript GFF. Its outputs match all 20 retained BED/GFF files byte for byte.
3. Run sections 1, 2, 2a and 3 from `prepared_s6/depth_cortex_30bp`. Set `WD` in section 1 to that directory and set `PLAIN`/`DARK` in sections 1–2 to your indexed BAM paths. Section 2a converts the two mosdepth region tables into the normalized bedGraphs consumed by section 3.
4. For S6B, run sections 4–5 from `prepared_s6`. Set section 4's `WD` to that directory and its `BAM` to the absolute path of your Light-pool BAM. The GFF supplies exons from all annotated transcripts on chromosome 8. Overlapping or adjacent exons are merged, and their chromosome-wide complement defines non-exonic sequence. A global 100-bp window is classified only when its entire length is exonic or non-exonic; mixed windows are excluded.
5. The GWA interval is 2,012,000–2,613,000 in one-based coordinates, represented as BED `[2011999, 2613000)`. Classify windows first, then cut them at the GWA boundaries to make the inside/outside sets. This reproduces the saved 1-bp inside fragment `[2011999, 2012000)` and 99-bp outside fragment `[2011900, 2011999)`. Keep intervals fully inside the chromosome core after excluding 200,000 bp at each chromosome end. These details are retained from the saved inputs rather than replacing fragments with full windows.
6. The final S6B sets contain 587 exonic and 5,051 non-exonic intervals inside the GWA interval, and 10,448 exonic and 113,048 non-exonic intervals outside it. All four sets match the coordinates of the retained mosdepth files used by the plotting script.
7. S6A divides each window mean by the mean reported for the whole chromosome, including zero-depth bases. The retained denominators are 106.33 for Plain/Light and 81.49 for Dark. Section 2a reads these values from each new mosdepth whole-chromosome result and writes six significant digits, matching all 8,942 retained normalized rows. S6B retains its original mean-depth values on the x-axis; the histogram y-axis is probability density. No chromosome-depth scaling is added to S6B.
8. The cortex preparation retains the saved BED span `[2428968, 2563072)` and selects the RefSeq transcript `rna-XM_076117071.1` with its exons and CDS records. The historical `cortex_padded_50kb` label is retained as an identifier; the span is explicit and is not recalculated from the current gene model. Section 3 retains its original cortex zoom and plotting settings.

### 0. Prepare exon/non-exon and cortex intervals from the annotation

**Save as:** `prepare_s6_intervals.py`

Run `python3 prepare_s6_intervals.py --gff /path/to/genomic.gff --fai /path/to/reference.fna.fai --out /path/to/prepared_s6`. The output directory must be new. Defaults reproduce S6; `--help` lists the chromosome, interval, window and transcript arguments. Cortex output filenames retain the interfaces used by the supplied depth/plotting scripts.

```python
#!/usr/bin/env python3
"""Prepare the retained S6 BED/GFF inputs from a RefSeq GFF and FASTA index."""
import argparse
import gzip
from pathlib import Path
from urllib.parse import unquote


def merged_intervals(intervals):
    merged = []
    for start, end in sorted(intervals):
        if merged and start <= merged[-1][1]:
            merged[-1] = (merged[-1][0], max(end, merged[-1][1]))
        else:
            merged.append((start, end))
    return merged


def complement(intervals, length):
    result, cursor = [], 0
    for start, end in intervals:
        if cursor < start:
            result.append((cursor, start))
        cursor = end
    if cursor < length:
        result.append((cursor, length))
    return result


def contained_windows(windows, regions):
    result, j = [], 0
    for start, end in windows:
        while j < len(regions) and regions[j][1] <= start:
            j += 1
        if j < len(regions) and regions[j][0] <= start and end <= regions[j][1]:
            result.append((start, end))
    return result


def split_at_interval(windows, left, right):
    inside, outside = [], []
    for start, end in windows:
        if start < right and end > left:
            inside.append((max(start, left), min(end, right)))
            if start < left:
                outside.append((start, left))
            if end > right:
                outside.append((right, end))
        else:
            outside.append((start, end))
    return inside, outside


def main():
    p = argparse.ArgumentParser(description=__doc__)
    p.add_argument('--gff', type=Path, required=True)
    p.add_argument('--fai', type=Path, required=True)
    p.add_argument('--out', type=Path, required=True, help='New output directory')
    p.add_argument('--chrom', default='NC_134752.1')
    p.add_argument('--window', type=int, default=100)
    p.add_argument('--end-trim', type=int, default=200000)
    p.add_argument('--gwas-start', type=int, default=2012000, help='One-based inclusive')
    p.add_argument('--gwas-end', type=int, default=2613000, help='One-based inclusive')
    p.add_argument('--cortex-start', type=int, default=2428969, help='Retained padded span, one-based inclusive')
    p.add_argument('--cortex-end', type=int, default=2563072, help='One-based inclusive')
    p.add_argument('--cortex-window', type=int, default=30)
    p.add_argument('--transcript-id', default='rna-XM_076117071.1')
    args = p.parse_args()
    if args.out.exists():
        p.error('Use a new output directory to preserve existing files')
    with args.fai.open() as handle:
        lengths = [int(f[1]) for line in handle for f in [line.split()]
                   if len(f) >= 2 and f[0] == args.chrom]
    if len(lengths) != 1 or lengths[0] <= 0:
        p.error('The requested chromosome must occur exactly once in the FASTA index')
    length = lengths[0]
    if args.window <= 0 or args.cortex_window <= 0 or not 0 <= args.end_trim < length / 2:
        p.error('Window lengths must be positive and the trimmed chromosome core nonempty')
    for start, end in [(args.gwas_start, args.gwas_end), (args.cortex_start, args.cortex_end)]:
        if not 1 <= start <= end <= length:
            p.error('Requested coordinates lie outside the chromosome')

    # GFF starts are one-based; BED intervals are zero-based, end-exclusive.
    exons, features, transcript_count = [], [], 0
    opener = gzip.open if args.gff.suffix == '.gz' else open
    with opener(args.gff, 'rt') as handle:
        for line in handle:
            if line.startswith('##FASTA'):
                break
            if line.startswith('#'):
                continue
            fields = line.rstrip('\r\n').split('\t')
            if fields[0] != args.chrom:
                continue
            if len(fields) != 9:
                p.error('Expected nine GFF columns')
            start, end = int(fields[3]) - 1, int(fields[4])
            if not 0 <= start < end <= length:
                p.error('GFF feature coordinates lie outside the chromosome')
            if fields[2] == 'exon':
                exons.append((start, end))
            attrs = dict(item.split('=', 1) for item in fields[8].split(';') if '=' in item)
            parents = [unquote(item) for item in attrs.get('Parent', '').split(',')]
            is_transcript = fields[2] == 'mRNA' and unquote(attrs.get('ID', '')) == args.transcript_id
            if is_transcript:
                transcript_count += 1
            if is_transcript or (fields[2] in ('exon', 'CDS') and args.transcript_id in parents):
                features.append('\t'.join(fields) + '\n')
    if not exons or transcript_count != 1:
        p.error('Expected annotated exons and exactly one selected cortex mRNA')
    exons = merged_intervals(exons)
    nonexonic = complement(exons, length)
    windows = [(start, min(start + args.window, length)) for start in range(0, length, args.window)]
    args.out.mkdir(parents=True)

    def write_bed(name, intervals, label=None):
        with (args.out / name).open('w') as handle:
            for start, end in intervals:
                suffix = '\t' + label if label is not None else ''
                handle.write(f'{args.chrom}\t{start}\t{end}{suffix}\n')

    write_bed(f'chrom.{args.chrom}.bed', [(0, length)])
    write_bed(f'core.{args.chrom}.{args.end_trim}bptrim.bed', [(args.end_trim, length - args.end_trim)])
    write_bed(f'gwas_interval.{args.chrom}.bed', [(args.gwas_start - 1, args.gwas_end)])
    write_bed(f'exons.{args.chrom}.merged.bed', exons)
    write_bed(f'nonexonic.{args.chrom}.bed', nonexonic)
    stem = f'windows.{args.chrom}.{args.window}bp'
    write_bed(stem + '.bed', windows)
    for label, regions in [('EXONONLY', exons), ('NONEXONONLY', nonexonic)]:
        pure = contained_windows(windows, regions)
        write_bed(f'{stem}.{label}.bed', pure)
        inside, outside = split_at_interval(pure, args.gwas_start - 1, args.gwas_end)
        for location, intervals in [('IN', inside), ('OUT', outside)]:
            write_bed(f'{stem}.{label}.{location}.bed', intervals)
            core = [(start, end) for start, end in intervals
                    if start >= args.end_trim and end <= length - args.end_trim]
            write_bed(f'{stem}.{label}.{location}.core{args.end_trim}.bed', core)

    cortex = Path('depth_cortex_30bp')
    (args.out / cortex).mkdir()
    left, right = args.cortex_start - 1, args.cortex_end
    # Keep the recorded span and legacy label; do not infer padding from a gene model.
    write_bed(cortex / 'cortex_padded.bed', [(left, right)], 'cortex_padded_50kb')
    write_bed(cortex / 'cortex_padded_30bp.bed',
              [(start, min(start + args.cortex_window, right))
               for start in range(left, right, args.cortex_window)])
    write_bed(cortex / f'{args.chrom}_full.bed', [(0, length)], args.chrom + '_full')
    transcript_name = args.transcript_id[4:] if args.transcript_id.startswith('rna-') else args.transcript_id
    with (args.out / cortex / f'cortex_{transcript_name}.features.uniq.gff').open('w') as handle:
        handle.writelines(dict.fromkeys(features))
    print(f'Wrote S6 BED/GFF inputs to {args.out}')


if __name__ == '__main__':
    main()
```

### 2a. Normalize cortex-window means to whole-chromosome means

**Save as:** `normalize_s6_cortex.py`

After sections 1–2, run `python3 normalize_s6_cortex.py /path/to/prepared_s6/depth_cortex_30bp`. The script reads the two cortex depth tables, the two whole-chromosome region tables and the prepared BEDs. It checks that the baselines cover the whole chromosome and that the depth rows match the cortex windows. It preserves zero-depth windows and the final shorter window, and requires that the normalized output files do not already exist.

```python
#!/usr/bin/env python3
"""Normalize retained S6A window means by each pool's reported chromosome mean."""
import argparse
import gzip
import math
from pathlib import Path


def rows(path):
    opener = gzip.open if path.suffix == '.gz' else open
    with opener(path, 'rt') as handle:
        for line in handle:
            if line.strip():
                yield line.split()


def normalized_rows(depth_file, baseline_file, expected_bed, chromosome_bed, chrom):
    baseline = list(rows(baseline_file))
    if len(baseline) != 1 or len(baseline[0]) not in (4, 5):
        raise ValueError('Expected one whole-chromosome mosdepth region row')
    fields = baseline[0]
    length, mean = int(fields[2]), float(fields[-1])
    if fields[0] != chrom or int(fields[1]) != 0 or length <= 0:
        raise ValueError('Invalid chromosome baseline coordinates')
    chromosome = list(rows(chromosome_bed))
    if len(chromosome) != 1 or chromosome[0][:3] != [chrom, '0', str(length)]:
        raise ValueError('Baseline must cover the prepared whole-chromosome BED')
    if not math.isfinite(mean) or mean <= 0:
        raise ValueError('Chromosome mean must be finite and positive')
    expected = [(f[0], int(f[1]), int(f[2])) for f in rows(expected_bed)]
    actual, output = [], []
    for fields in rows(depth_file):
        if len(fields) != 4:
            raise ValueError('Expected four columns for cortex-window depths')
        start, end, depth = int(fields[1]), int(fields[2]), float(fields[3])
        if fields[0] != chrom or not 0 <= start < end <= length:
            raise ValueError('Invalid cortex-window coordinates')
        if not math.isfinite(depth) or depth < 0:
            raise ValueError('Window depth must be finite and nonnegative')
        actual.append((fields[0], start, end))
        # Six significant digits reproduce the retained bedGraph formatting.
        output.append(f'{chrom}\t{start}\t{end}\t{depth / mean:.6g}\n')
    if not expected or actual != expected:
        raise ValueError('Depth rows must match the prepared cortex BED in order')
    return ''.join(output), mean


def main():
    p = argparse.ArgumentParser(description=__doc__)
    p.add_argument('depth_dir', type=Path)
    p.add_argument('--chrom', default='NC_134752.1')
    p.add_argument('--baseline-prefix', default='NC_134752_mean')
    args = p.parse_args()
    pending = []
    for sample in ('plain', 'dark'):
        output = args.depth_dir / f'{sample}.cortex30.norm.bedgraph'
        if output.exists():
            p.error(f'Output already exists: {output}')
        try:
            text, mean = normalized_rows(
                args.depth_dir / f'{sample}.cortex30.regions.bed.gz',
                args.depth_dir / f'{sample}.{args.baseline_prefix}.regions.bed.gz',
                args.depth_dir / 'cortex_padded_30bp.bed',
                args.depth_dir / f'{args.chrom}_full.bed', args.chrom)
        except (OSError, ValueError, IndexError) as exc:
            p.error(str(exc))
        pending.append((output, text, sample, mean))
    for output, text, sample, mean in pending:
        with output.open('x') as handle:
            handle.write(text)
        print(f'{sample}: chromosome mean {mean:g}; wrote {output}')


if __name__ == '__main__':
    main()
```

#!/usr/bin/env Rscript

# Histogram B: core region (±200 kb trimmed)
suppressPackageStartupMessages({
  library(data.table)
  library(ggplot2)
})

outdir <- "mosdepth_plain_NC_134752.1_100bp_purewindows_core200000"

files <- list(
  IN_exon     = file.path(outdir, "plain.windows.NC_134752.1.100bp.EXONONLY.IN.core200000.regions.bed.gz"),
  IN_nonexon  = file.path(outdir, "plain.windows.NC_134752.1.100bp.NONEXONONLY.IN.core200000.regions.bed.gz"),
  OUT_exon    = file.path(outdir, "plain.windows.NC_134752.1.100bp.EXONONLY.OUT.core200000.regions.bed.gz"),
  OUT_nonexon = file.path(outdir, "plain.windows.NC_134752.1.100bp.NONEXONONLY.OUT.core200000.regions.bed.gz")
)

read_regions <- function(path, region_type, locus) {
  dt <- fread(cmd = paste("zcat", shQuote(path)), header = FALSE)
  setnames(dt, c("chr","start","end","depth"))
  dt[, region_type := region_type]
  dt[, locus := locus]
  dt
}

dt <- rbindlist(list(
  read_regions(files$IN_exon,     "Exonic (100bp pure)",     "Inside GWAS interval"),
  read_regions(files$IN_nonexon,  "Non-exonic (100bp pure)", "Inside GWAS interval"),
  read_regions(files$OUT_exon,    "Exonic (100bp pure)",     "Outside interval (core; ±200kb trimmed)"),
  read_regions(files$OUT_nonexon, "Non-exonic (100bp pure)", "Outside interval (core; ±200kb trimmed)")
))

ann <- dt[, .(
  n  = .N,
  n0 = sum(depth == 0),
  p0 = 100 * sum(depth == 0) / .N
), by = .(locus, region_type)]

binwidth <- 2

p <- ggplot(dt, aes(x = depth, fill = region_type)) +
  geom_histogram(aes(y = after_stat(density)),
                 binwidth = binwidth, boundary = 0,
                 position = "identity", alpha = 0.30) +
  facet_wrap(~ locus, ncol = 1, scales = "fixed") +
  geom_text(
    data = ann,
    aes(label = sprintf("%s: %.1f%% zeros (n=%d)", region_type, p0, n)),
    x = 0, y = Inf, hjust = 0, vjust = 1.2,
    inherit.aes = FALSE, size = 3.4
  ) +
  labs(
    title = "Plain sample: coverage distribution (MAPQ>=30)",
    subtitle = "100 bp pure windows; chromosome ends (±200 kb) excluded; histogram scaled to density.",
    x = "Depth",
    y = "Density",
    fill = "Region set"
  ) +
  theme_classic(base_size = 12)

ggsave("plain.coverage_hist.100bp_purewindows.core200kb.LINEAR_full.IN_vs_OUT.pdf",
       p, width = 8, height = 7.5, units = "in")
